# Multimodal AI Assistant

A powerful AI assistant designed to generate both text and images seamlessly, leveraging state-of-the-art technologies to deliver an engaging and interactive experience.

## Key Features

### Frontend
- Built with **React.js** to provide a dynamic and user-friendly interface.
- Ensures a smooth and responsive user experience for effective interaction.

### Backend
- Developed using **Node.js** and **Express.js**, enabling robust and efficient server-side operations.
- Handles requests and API integrations with high performance and scalability.

### API Integrations
- **Gemini AI API**: Utilized for advanced text generation, delivering accurate and contextually relevant outputs.
- **Hugging Face Stable Diffusion API**: Integrated for creating high-quality, realistic images tailored to user prompts.

### Automation & Debugging
- Automatic saving of generated images to a preconfigured file path for streamlined organization.
- Comprehensive logging of both user prompts and generated outputs (text and images) in the console for traceability and debugging purposes.
